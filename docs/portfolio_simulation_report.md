- **同月前视已修**：仓位信号改为取**严格早于当月**的最近一期预测。旧版用 `index <= 月末`（含当月月末）的信号去定当月仓位，而 HAR/回撤预测的目标本就是下一个月 —— 等于用期末信息交易整月收益。
- **期限错配已修**：取 t < m 的那一期，恰好就是「对 m 月的预测」。
- **现金计息**：未投资部分按无风险利率计息；期初从现金（仓位 0）出发，首月如实收取建仓成本。
- **选样**：组合基金按 OOS 起点之前的覆盖度挑，但仍受「当前存续基金」这一层幸存者偏差影响。
- **回撤标签**：月内最大回撤在**复权净值**（累计净值，除息日不下挫）上计算；旧版直接用单位净值，分红会污染标签。
- **阈值的选择**：回撤阈值来自对 OOS 的敏感性搜索，属于样本内选型 —— 本报告的绝对 AUC 因此偏乐观。
