## 2. 两个阈值的实测位置

### 2.1 `momentum_warning: 40` —— 完全失效

| 类型组 | 该组近3月动量的 P99 | `≤40` 的通过率 | 判定 |
|---|---|---|---|
| A 偏股混合 | **22.06%** | 99.5% | ❌ 阈值在分布之外 |
| B 灵活配置 | — | **100.0%** | ❌ |
| C 主动股票 | — | **100.0%** | ❌ |
| D 指数股票 | — | **100.0%** | ❌ |
| E 债券 | — | **100.0%** | ❌ |

**A 组近 3 月动量的最大值（P99）才 22%** —— 而阈值设在 40%。
**这个"追涨警告"从上线至今从未触发过一次。**

**正确的量级**：若要拦"涨幅前 5%"，A 组应为 **6.61%** —— 与 40% 相差 **6 倍**。

### 2.2 `max_drawdown_1y: 35` —— 偏松且分类型严重不均

| 类型组 | 阈值在同类分布中的位置 | 通过率 |
|---|---|---|
| A 偏股混合 | **P77** | 77.5% |
| B 灵活配置 | **P89** | 89.5% |
| C 主动股票 | **P84** | 83.5% |
| **D 指数股票** | **P98** | **98.1%** |
| **E 债券** | **P100** | **100.0%** |

**同一个 35%，在 A 组是 P77（还有点筛选力），在债券组是 P100（等于没设）。**

债券组近1年回撤的 P75 才 **1.60%** —— 35% 对它是天文数字。
**这是「必须分类型」最直接的实证。**

## 3. 建议的替代方案：阈值改为同类分位

```
max_drawdown_1y: 35          →  回撤 ≤ 同类 P75
momentum_warning: 40         →  涨幅 ≥ 同类 P95（样本不足的组用 P90）

按当前实测数据落成的具体数值：
┌──────────────┬──────────────────┬────────────────────┐
│ 类型组        │ 回撤阈值(≤P75)    │ 动量警告(≥P95/P90)  │
├──────────────┼──────────────────┼────────────────────┤
│ A 偏股混合     │ 33.58%           │ 6.61%  (P95)       │
│ B 灵活配置     │ 26.00%           │ 3.05%  (P90)       │
│ C 主动股票     │ 30.98%           │ −0.57% (P75)⚠️      │
│ D 指数股票     │ 23.58%           │ 0.89%  (P90)       │
│ E 债券        │ 1.60%            │ 0.51%  (P75)⚠️      │
└──────────────┴──────────────────┴────────────────────┘

⚠️ C/E 组样本不足以估 P90/P95，只能用 P75 —— 该警告在低样本组会偏敏感，需标注
```

**改为分位阈值的好处**：市场整体波动放大时，P75 自动跟着上移，
不需要人工调参，也不会像现在这样"熊市里失效、牛市里误杀"。

## 4. 顺带读出的市场信息

| 观察 | 数值 | 含义 |
|---|---|---|
| A 组近3月动量**中位数** | **−6.09%** | 近 3 个月偏股混合整体在跌，**一半以上的基金是负收益** |
| A 组近1年回撤中位数 | 24.62% | 比拍脑袋的 35% 更接近真实 |
| E 组夏普中位数 | 0.93 | 债券组风险调整后收益显著高于权益（A 组仅 0.20） |
| 各组近3月动量中位数**全为负** | A −6.09 / B −1.26 / C −3.70 / D −4.95 | 全市场近期都在回调 |

> 这解释了用户组合当前收益率 **−1.78%** —— 不是选基问题，是市场整体在跌。
> **参照系的价值正在于此：把「市场 beta」和「基金优劣」分开。**
