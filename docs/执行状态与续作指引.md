## 3. ⚠️ 唯一的尾巴

### 3.1 `purchase_fee_rate` 定义了但**未接入买入路径**

```python
portfolio.py:84   def purchase_fee_rate(fund_name, default=DEFAULT_PURCHASE_FEE)   # 已定义并被测试覆盖
portfolio.py:495  shares = round(amount / confirm_nav, 2)                          # 未使用它
```

正确口径（D1 页面原文）：
```
净申购金额 = 申购金额 / (1 + 申购费率)
申购份额   = 净申购金额 / T日基金份额净值
```

**当前影响 = 0**：用户 7/7 持仓均为 C 类，费率 0，`amount/nav` 恰好正确。
**对 A 类份额会高估份额** `fee/(1+fee)`（1.5% 费率 → 高估约 1.48%），属通用化阻塞项（对应任务书 §5.2）。

**处置**：买入路径改为 `net = amount / (1 + purchase_fee_rate(name))`，`shares = round(net / nav, 2)`，
并把申购费用记入 `transactions.fee`。**须保证 C 类结果与现值完全一致**（防回归）。
