### 五、⚠️ 上一会话踩到的坑（会直接咬到你，务必先看）

1. **推送必须用 SSH 显式 URL** —— `origin` 配的是 HTTPS，**实测 502 不通**：
   `git push git@github.com:Mo12y/Quantitative-Fund-auto.git main`。
   沙箱里 `git status` 恒显示 `[gone]` → **判断同步以 `git ls-remote` 为准**。
2. **报绝对收益而不报基准 = 默认读者会把 beta 当 alpha**（P1 的教训）。
   任何"我赚了多少/亏了多少"的口径，**都要带同期基准**。
3. **报分布而不报极差 = 可能把假信号当结论**：E 组"信度 80.8%"其实是**2 只**净值几乎不动
   的基金（年化波动 0.019%）撑起来的假象 —— 只剔 2 只，信度就掉到 52%。
   **极端值不需要多，2 个就能篡改统计结论。**
4. **改含反引号的文档不要用 shell 传字符串** —— 反引号会被 shell 当命令执行、吃掉内容
   （上一会话真踩到，`python -c "...\`code\`..."` 把两行文档吃没了）。**用编辑工具改。**
5. **合成测试数据要带波动** —— 零波动序列的夏普会被值域守卫正确置为 NaN，
   让"排序类"断言失效（`test_batch4_recsys._seed` 已补 ±0.5% 确定性摆动）。
6. **缓存粒度**：按"基金代码"缓存净值路径，会让**同一基金的多笔买入共用一条路径**
   → `path[0]` 取到前一笔日期的净值 → **买入成本算错**。缓存键必须是 `(code, date)`。
7. **`nav_metrics.MIN_ANN_VOL_FOR_RATIO = 0.005`** —— 改了它必须**重建物化表 +
   重算参照系缓存**，否则两处口径不一致。
8. **`peer_percentile.CACHE_VERSION`** —— 改了缓存结构必须同步升版本，否则旧缓存永不过期。
9. `.workbuddy/memory/` **不在 git 里**（被 `.gitignore` 忽略）→
   权威记录是 `AGENTS.md` + `docs/agents/HANDOFF.md` + `docs/审计修复记录.md`。
