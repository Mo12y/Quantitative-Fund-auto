# 使用指南

> 假设你什么都不懂。读完这篇就够了。

---

## 一、这个东西是干嘛的？

它是一个**帮你管住手**的工具。

支付宝会告诉你"最近这只基金涨了30%，快买"——你买了，然后它跌了。
支付宝会告诉你"市场大跌，你的基金亏了15%"——你慌了，卖了，然后它涨回去了。

这个系统的逻辑反过来：
- **市场冷的时候**（大家都在卖、很恐慌）：提醒你该买
- **市场热的时候**（大家都在买、很兴奋）：提醒你该卖或者别追
- **大多数时候**：告诉你"别动，下周再来"

它不告诉你买哪只会涨（没人知道），但它告诉你**现在出手划不划算**。

## 二、安装（只做一次）

你已经做过了，跳过。新电脑上：

```bash
pip install -r requirements.txt
python src/main.py collect    # 拉取全市场基金数据（2分钟）
python src/main.py nav        # 拉取基金净值历史（5分钟）
python src/main.py enrich     # 补充详情（2分钟）
```

## 三、每周就一条命令

```bash
python src/main.py
```

**就这么简单。** 每周跑一次，看一眼，关掉。

## 四、怎么看报告？

### 首先看温度

```
🌡️ 温度: [███████████░░░░░░░░░] 57.4°C
  状态: 🌤️ 适中
  建议: 正常水平，保持定投
```

温度就像体温计——数字越高=市场越"发烧"：

| 温度 | 意思 | 你应该 |
|------|------|--------|
| 0-20° | 🧊 大家都吓坏了，没人敢买 | **如果有闲钱，这是好时机** |
| 20-40° | 💧 市场偏冷 | 可以适当多买点 |
| 40-60° | 🌤️ 正常 | 按计划来，不追加 |
| 60-80° | 🔥 有点热了 | 别追了，手里有的拿着 |
| 80-100° | ☀️ 在发烧 | **考虑卖一部分落袋为安** |

当前温度 57.4°C —— 正常偏热一点。不动。

### 然后看仓位建议

```
🎯 建议权益仓位: 35.0%
🎯 建议债券/货币仓位: 65.0%
```

你有 1,000 元。
- 权益 = 买股票型/混合型基金，约 350 元
- 债券/货币 = 放余额宝或纯债基金，约 650 元

### 然后看信号

```
📰 PMI=49.2，制造业继续下滑
   对股市偏利空，利好债券
```

PMI 是国家统计局每个月发布的制造业数据。大于50=经济扩张，小于50=经济收缩。49.2=经济在收缩方向。这条信号的意思是："别急，再等等看"。

### 其余部分

大部分时候你不需要看。质量筛选池是你想买基金的时候可以参考的名单（🟢=没大毛病），持仓跟踪是你录入了持仓之后才有东西。

## 五、怎么实际操作？

### 你想买的时候

1. 看一眼温度。如果 > 60°，别买。如果 < 40°，可以多买。
2. 在支付宝搜索 "**000313**"（华安沪深300增强C），买200-300元。
3. 回到命令行：

```bash
python src/main.py buy
```

按照提示输入：基金代码 000313，名称 华安沪深300增强C，买入金额，日期。

### 你想卖的时候

1. 看一眼温度。如果 > 80°，考虑卖一部分。如果 < 60°，别卖。
2. 在支付宝操作卖出。
3. 回到命令行：

```bash
python src/main.py sell
```

### 你什么都不想做的时候

**这其实就是大多数时候。** 关掉命令行，下周再看。

频繁操作是散户亏钱的第一原因。这个系统存在的意义就是让你**少操作**。

## 六、Web 仪表盘（最直观的方式）

不想看命令行的话，启动网页版：

```bash
python src/main.py web
```

浏览器会自动打开 `http://localhost:5020`。

页面上有四个卡片：
- 🌡️ **市场温度计** — 当前冷热，一目了然
- 🎯 **仓位建议** — 该配多少权益、多少债券
- 📰 **消息信号** — 最近有没有值得关注的事
- 🔍 **基金质量池** — 🟢稳健的基金名单，带30日净值走势图

往下滚动还有：
- 📊 **31行业板块排名** — 哪些行业正在涨、哪些超跌
- 🏆 **历史验证推荐** — 回测选出的基金，含实际收益验证
- 🔄 **调仓建议** — （如果你录入了持仓）告诉你要不要调、调多少

**建议：每周打开网页看一次，比命令行报告更直观。**

## 七、其他偶尔有用的命令

| 命令 | 什么时候用 |
|------|-----------|
| `python src/main.py temp` | 想看温度详情（风格、分歧） |
| `python src/main.py score` | 想买基金的时候看看🟢名单 |
| `python src/main.py portfolio` | 看看自己赚了还是亏了 |
| `python src/main.py sentiment` | 看看最近有没有大事（LPR降息、经理换人） |
| `python src/main.py sector` | 看31个行业排名，找轮动方向 |
| `python src/main.py recommend` | 历史回测选出的基金（需跑15-20秒） |
| `python src/main.py rebalance` | 需要调仓时，看具体买卖指令 |

## 八、如果你全仓了某个行业

比如你全买了半导体基金。

系统的大盘温度对你参考价值有限——你可能在大盘温和的时候独自亏30%。

但系统能告诉你：
- **追涨警告**：半导体近1年涨了85% → "近3月涨40%"就会被标记⚠️，85%意味着你买在山顶的风险很大
- **集中度问题**：全仓一个行业，波动是大盘的2-3倍

你可以额外关注你那个行业的指数走势，但目前系统没有行业温度计。

## 九、一句话总结

> **每周跑一次 `python src/main.py`。温度<40考虑买，>60考虑卖，中间不动。关掉，下周再见。**
