## 一、这个东西是干嘛的？

它是一个**帮你管住手**的工具。

支付宝会告诉你"最近这只基金涨了30%，快买"——你买了，然后它跌了。
支付宝会告诉你"市场大跌，你的基金亏了15%"——你慌了，卖了，然后它涨回去了。

这个系统的逻辑反过来：
- **市场冷的时候**（大家都在卖、很恐慌）：提醒你该买
- **市场热的时候**（大家都在买、很兴奋）：提醒你该卖或者别追
- **大多数时候**：告诉你"别动，下周再来"

它不告诉你买哪只会涨（没人知道），但它告诉你**现在出手划不划算**。

## 二、安装与数据准备

### 第一次装（只做一次）

```bash
pip install -r requirements.txt
python src/main.py init        # 一条龙：自检 → 采集基金列表+指数 → 净值 → 详情
```

也可以分步跑（任一条失败不影响其它）：

| 命令 | 干什么 | 大概多久 |
|------|--------|---------|
| `python src/main.py test` | 测试数据接口通不通 | 几秒 |
| `python src/main.py collect` | 拉全市场基金列表 + 指数估值 | 几分钟 |
| `python src/main.py index` | 单独更新指数估值(PE/PB) | 几十秒 |
| `python src/main.py nav` | 拉候选基金的净值历史（质量筛选要它） | 几分钟 |
| `python src/main.py enrich` | 补基金详情（经理/规模/费率） | 几分钟 |
| `python src/main.py hithink` | 测试同花顺 HiThink 接口 | 几秒 |

### 数据多久更新一次？

- **看温度/仓位**：数据在本地 `data/fund_quant.db`。⚠️ 这个库**不在仓库里**
  （`.gitignore` 排除，因为它含你的真实持仓），所以新克隆一份之后**必须先跑 `python src/main.py init`** 才有数据。
- 建好之后多数时候**不用天天拉**，直接开网页看即可；想更新就重跑对应命令，没有强制频率。
- 数据源默认用 **akshare**（免费、无需 key）；想用同花顺 HiThink 则配好 `HITHINK_API_KEY`
  （写到 `.env` 或设成环境变量都行），再用 `hithink` 测试。
- 网页里的温度默认用**本地快照离线算**（快、不联网）；`python src/main.py temp` 会联网取最新的
  LPR 利率与申万风格指数，因此更新鲜。两边的**量能维度都读本地 `index_daily.volume`**，
  正常情况下数值应当接近。若某个维度数据缺失，离线路径会**剔除该维度、按剩余权重重新归一化**
  并提示"数据缺失维度已剔除…"，而不是静默填一个中性值顶替。

## 三、怎么用？——最常用的方式：网页版

启动看板：

```bash
python src/main.py web
```

浏览器打开 `http://localhost:5020`。页面是**左侧侧边栏 + 面板**，点侧边栏切换。各面板看什么：

### 📈 总览（默认打开）
第一眼给结论的四块数字：**市场温度、建议权益仓位、持仓市值盈亏、计划投入**。下面还有温度详情卡、仓位卡、市场信号卡（LPR/PMI/基金公告，需要时会显示“扫描中”，几十秒内自动出结果，不影响其它）。

### 💼 持仓 · 计划 · 调仓
你的实际组合与动作：
- **投资计划**进度（已投/目标、每只基金目标比例）
- **持仓明细** —— 在这里**加仓/减仓/修改/删除**（见第五节）
- **调仓建议** —— 录入持仓后，会告诉你要不要调、卖/买什么、为什么
- **📅 定投计划** —— 添加、暂停/恢复、执行、删除（见第七节）

### 🔍 基金筛选池
🟢🟡🔴 质量筛选。**它只帮你排除“有坑”的基金**（费率、回撤、经理、清盘风险等），不是帮你挑“会涨的黑马”。

### 🗂️ 行业板块
31 个申万行业综合排名（动量 40% + 趋势 30% + 风险调整 30%）+ 排名靠后（值得注意）。板块数据要联网拉取并缓存，第一次可能显示“加载中/等待数据”，等缓存好或点“⚡ 重算”即可。

### 🧪 量化模型
波动率预测多模型对比、回撤预警、组合模拟（OOS 2023–2026），用离线 CSV 展示模型研究结果。看得懂再看，看不懂跳过不亏。

> 注：目前“历史验证推荐”没有做成网页卡片，想看用命令行 `python src/main.py recommend`（见第八节）。

**页面顶栏**还有一个 **`⚡ 重算数据`**：强制重新跑温度/筛选/调仓等分析并刷新（约 10 秒），适合想立刻看到最新结果时点。

## 四、报告/页面怎么看 + 该怎么决定

### 第一步：看温度（0–100）

温度就像体温计——数字越高=市场越“发烧”：

| 温度 | 意思 | 你应该 |
|------|------|--------|
| 0-20° | 🧊 大家都吓坏了，没人敢买 | **如果有闲钱，这是好时机** |
| 20-40° | 💧 市场偏冷 | 可以适当多买点 |
| 40-60° | 🌤️ 正常 | 按计划来，不追加 |
| 60-80° | 🔥 有点热了 | 别追了，手里有的拿着 |
| 80-100° | ☀️ 在发烧 | **考虑卖一部分落袋为安** |

### 第二步：看仓位建议

```
🎯 建议权益仓位: 28.8%    权益 = 股票/混合型基金
🎯 建议债券/货币仓位: 71.2%  固收 = 余额宝/纯债/短债
```

（上面是 2026-09-11 温度 56.3° 时的实际输出，你的会随温度变。）
仓位是**连续插值**出来的，不是查档位表 —— 温度从 39.9° 挪到 40.0° 只会让仓位动 0.1pp，
不会像旧版那样一次跳 20 个百分点。

**总资金口径**：调仓面板里的"总资产"= 持仓**市值** + 计划里的**现金弹药**，
和计划卡上的数字同源；不再用"投入 × 1.1"这类估算。

### 第三步：看信号与调仓

- **信号**（如 PMI<50=经济收缩、LPR 降息利好股市等）只告诉你“现在要不要急”。
- **调仓建议**（网页持仓页下方）：会列出具体的 `卖出` / `买入` 指令和金额。要点：
  - 指令金额 = 目标仓位 − 当前仓位换算出来的钱，别手动拍脑袋。
  - **持有不满 7 天赎回有 1.5% 惩罚费** —— 系统会提醒你“不急就先等满 7 天”。

### 把温度落到操作

> **温度 <40 考虑买，>60 别追，>80 考虑卖。中间不动。**

买不买、卖不卖，都先看温度这一条。信号和调仓只是帮你把“买/卖”执行得更细。

## 五、实际操作：加仓 / 减仓

**优先在网页上操作，不用敲命令。** 打开「💼 持仓·计划·调仓」：

**加仓 / 买入**
1. 顶部表单填 **基金代码**（名称留空会自动补全）、**金额**、**日期**（默认今天）；
2. 点 **记买入**。系统按**申请日（T 日）净值**折算份额入库。

> **定价口径（T+1 规则）**：15:00 前提交按**申请日当天净值**成交，份额次日（T+1）确认，
> 收益从 T+2 起算；15:00 后提交或遇非交易日则顺延。持仓表里的"**定价日**"列就是成交所用的那一天，
> 点开每只基金可看到。确认日净值尚未公布时，状态会显示"**待确认·净值未公布**" —— 系统**不会**
> 拿邻近某天的净值凑一个数，等净值出来再自动结算。

**减仓(卖) / 修改 / 删除**
- 每只持仓右侧有 `➖ 减仓(卖)`、`✏️ 修改`、`🗑 删除`；
- 点后按提示输入卖出金额/日期即可（都有确认弹窗，防误点）；
- 操作完页面会自动重算市值、盈亏与调仓建议。

> **卖出支持部分减仓**：卖出金额小于当前市值时，按比例扣减份额与成本，剩余份额继续持有（T+1 确认后才生效，期间该持仓显示"待确认卖出"）。全部卖完后状态变为"已卖出"，进入下方「已了结」明细。
> 命令行 `python src/main.py sell` 同样按金额卖出，也支持只卖一部分。

> **赎回费**：监管要求持续持有期少于 7 日的赎回费不低于 **1.5%**。系统按
> "赎回确认日 − 申购确认日"计算持有天数：**不足 7 天**按 1.5%（若采到了基金自己的费率则用更大的那个）；
> **满 7 天一律为 0**（C 类份额口径，没有"7–30 天 0.5%"那一档）。
> 费用计入该笔卖出的**赎回费**，并体现在「已了结」明细与总览的"已实现收益"里。
> **短线卖出到底扣不扣钱，先看这里再下手。**

> **已实现收益**：总览新增一格，统计已了结卖出的落袋盈亏（卖出毛额 − 对应成本 − 赎回费）。
> 它与"累计收益"（未实现，只算在持份额）互不重复，两者相加才是这半年的总账。

> **历史成本的口径**：2026-09-10 之前入库的持仓，成本是按**旧口径（确认日 T+1 净值）**算的；
> 系统**没有回填**这些历史记录，只对新流水用申请日 T 净值。所以持仓表里会同时存在两种口径，
> 想评估"如果全部按新口径重算会差多少"，跑只读脚本：
> ```bash
> python scripts/rebuild_costs_dryrun.py     # 只读，不改数据
> ```

没有网页或不方便时，命令行等价：
```bash
python src/main.py buy         # 交互输入：代码/名称/金额/日期
python src/main.py sell        # 选持仓ID，输入金额
python src/main.py update      # 改金额/日期（改错时）
python src/main.py delete      # 删掉录错的持仓
```

## 七、定投（网页可全程操作）

**添加定投**（持仓页「📅 定投计划」卡）：
1. 填 **基金代码**、**每期金额**、**频率**（`daily`=日 / `weekly`=周 / `biweekly`=双周 / `monthly`=月）、**开始日期**；
2. 点 **＋ 添加定投**。

**管理**：
- 每个计划右侧：**执行**（仅“已到期”可用，会记一笔买入并推进下一期）、**暂停 / 恢复**、**删除**；
- 顶部 **▶ 执行全部到期**：把所有到期的计划都跑一期。

**提醒**
- 定投要“跑起来”需要你到点**手动执行一期**（网页或 `python src/main.py dca run`）。网页只负责把“执行买入”这步做掉。
- 想要**自动**到点执行，用后台定时器：`python src/main.py schedule`（每周日 20:00 自动生成周报，按需自己扩展定时任务）。

## 八、报告 / 推荐 / 回测 怎么读（别误用）

### `python src/main.py recommend` —— 历史验证推荐
从历史回测里挑“过去表现相对稳”的基金，并给每只的 3 个月平均收益验证。
⚠️ 这是**对过去的总结，不是对未来的预测**。当参考名单可以，别当“明天就涨”的圣旨。

### `python src/main.py backtest3`（严谨回测 v3）
用来回答"我这套选基金/调仓逻辑历史上到底行不行"。**净收益口径**（申购费/赎回费/管理费都已扣进指标），
双基准（沪深300 / 中证500）与策略**按日期对齐**，逐年按自然年分解。

⚠️ **它的结论是负面的**：月度 alpha 不显著（vs 沪深300 p=0.38，vs 中证500 p=0.56），
且逐年极不稳定（2022 −29.5%、2024 −8.0%，而 2025 +41.2%）。**不要把它当成"这套策略能赚钱"的证据**。

> 另一个常被引用的对照（`backtest4`）显示：改进假设被证伪，且"主动调仓能大幅降回撤"这个旧结论
> 在修正口径后**不成立**（买入持有 44.5% vs 现状 43.5%，只差 1pp）。详见 [README](../README.md#回测与研究v30)。

### 板块 / 量化模型面板
- 板块排名 = 当前轮动热度的参考（动量 40% + 趋势 30% + 风险调整 30%）。
- 量化模型 = 研究留档（vol 预测、回撤预警、组合模拟）。看懂再用来做判断。

**统一口径：** 这些工具给的是“统计参考/辅助判断”，不构成投资建议，更不保证收益。

## 九、常见问题与边界

**Q1：温度某个维度显示"缺失"？**
说明该维度**当期没有可用数据**（例如量能读不到）。系统会**剔除这个维度、把剩余维度按权重重新归一化**
让温度仍然可用，并在温度卡与命令行里明确提示"数据缺失维度已剔除…"。
这是**有意为之**，不是 bug —— 它不会再偷偷填一个 50 冒充"中性读数"（旧版就是这样，已修）。
想看更全的数据跑 `python src/main.py temp`（会联网补 LPR 与风格指数）。

**Q2：板块显示“加载失败 / 等待数据”？**
板块要联网抓取 31 个行业并缓存，首次或没网时会这样。稍等缓存好，或点顶栏 `⚡重算数据` / 刷新重试。

**Q3：市场信号一直“扫描中”？**
信号要联网扫 LPR/PMI/基金公告，几十秒内自动出；期间不影响其它面板。

**Q4：我的数据/记录在哪？会不会丢？**
都在这一个文件：`data/fund_quant.db`（持仓、定投、净值都在里面）。**备份 = 把这个文件复制一份存好**；删了/重装它就全没了。

**Q5：网页操作和命令行会冲突吗？**
不会，网页的加仓/减仓/定投与命令行走同一套逻辑、写同一个库。

**边界与风险提示**
- **别全仓一个行业**。比如全仓半导体，大盘温度对你就参考有限——你可能在大盘温和时独自亏 30%。系统能给你的行业集中度/追涨警示是提醒，不是行业温度计。
- 频繁操作是散户亏钱第一原因。多数时候系统的建议就是“别动”。

## 十、每周例行清单（傻瓜版）

每周任选一天做一遍，约 5 分钟：

1. `python src/main.py web` 打开网页；
2. 看**总览**：温度多少？建议仓位几成？
3. 看**市场信号**有没有大事（PMI<50、LPR 降息等）；
4. 有持仓就打开「持仓·计划·调仓」：需要调仓吗？定投有到期的吗？有就点 **执行**；
5. 真要买/卖，就在网页里 **记买入 / 减仓**（先看温度那一条再动手）；
6. 没有要做的，就关掉，下周再来。

想更省事：`python src/main.py schedule` 挂着，每周日 20:00 自动生成周报提醒你。
