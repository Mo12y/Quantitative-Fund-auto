# 口径引用索引.md — 改数字前先查这里

> **用途：改任何核心数字前，先在本文件查「谁引用了它」，改完回写。**
> 目的：**不盲 grep**；避免「SSOT 改了、引用没改」造成的自相矛盾。
> **最后更新：2026-10-14（S0，首次建立；引用点待随 S1/S3 补全）**

---

## 用法

对一个数字，先跑：

```bash
rg -n "<数字>" --glob '*.md' --glob '*.py' --glob '!docs/_archive/**'
```

命中列表即为「引用点」。改完数字 → **同步回写本表**。

> ⚠️ 排除 `docs/_archive/`：归档区的旧计数**不是过期，是历史真值**，**不要改**。
