#### 三、注意事项（坑，都踩过）

1. **`.workbuddy/memory/` 被 `.gitignore` 忽略、没进 git** —— 别把唯一副本写在那里。
   仓库内的权威记录是 `AGENTS.md` + 本文件 + `docs/审计修复记录.md` + `docs/前端重构计划书.md`。
2. **推送必须走 SSH 显式 URL**；沙箱 `git status` 恒显示 `[gone]`，**以 `git ls-remote` 为准**。
3. **后端三条端点有落盘快照缓存**（`source=snapshot`）：改了后端代码，页面仍读旧载荷，
   必须 `?fresh=1` 才重算 —— 否则会把"没生效"误判成"修复失败"。
4. **前端视觉验收不能用整页截图**：`background-attachment: fixed` 在 `full_page=True` 下
   只渲染顶部一屏，据此判断"背景够亮了"是错的。用视口截图。
5. **JSX 文本节点里的 `**粗体**` 会原样渲染**（后端文案有 `plainText()` 清洗，前端自己写的没有）。
6. **账本口径 ≠ bug 两例**：① 有部分卖出的批次 `buy_amount` 是**摊薄后剩余成本**；
   ② `transactions.amount` **只有买入有值**，卖出须用 `shares × confirm_nav`。
7. `transactions.kind` 存的是 **`buy`/`sell`**（英文），不是中文。
