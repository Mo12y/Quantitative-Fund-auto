#### 三、注意事项（坑，都踩过）

1. **`origin` 配的是 HTTPS，实测 502 不通** —— **推送必须用 SSH 显式 URL**；
   沙箱 `git status` 恒显示 `[gone]`，**以 `git ls-remote git@github.com:...` 为准**。
2. **`shrinkage` 的 τ² 是矩估计、且被 `max(0, ·)` 夹住** —— 出现 0 是"真信号不可检测"的**正常**结论，
   不是算错。ρ̄=0.61~0.70 会让 τ² 偏乐观（收缩偏弱），方向保守，故 0 是可信下界。
3. **`peer_percentile.CACHE_VERSION` = 2** —— 改了缓存结构必须同步升版本，否则旧缓存永不过期。
4. ⭐ **报绝对收益而不报基准 = 默认读者会把 beta 当 alpha**（P1 的教训）。
5. ⭐ **报分布而不报极差/极值 = 可能把假信号当结论**（E 组 80.8% 的教训，
   **2 只基金就能篡改统计结论**）。
6. **`nav_metrics.MIN_ANN_VOL_FOR_RATIO = 0.005`** —— 改了它必须**重建物化表 + 重算参照系**，
   否则两处口径不一致。
7. **合成测试数据要带波动** —— 零波动序列的夏普会被守卫正确置为 NaN，
   让"排序类"断言失效（`test_batch4_recsys._seed` 已补 ±0.5% 确定性摆动）。
8. 其余坑见上一块（`.workbuddy/memory` 不进 git / 落盘快照缓存 / 视觉验收用视口截图 /
   JSX 里 `**粗体**` 原样渲染 / `transactions.amount` 只有买入有值 / `kind` 存英文）。
