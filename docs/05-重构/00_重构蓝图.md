## 一、题目与定位

- **题目**：《**基于多源金融数据的个人投资者交易行为分析与建模**》
- **仓库名**：`fund-behavior-lab`
- **定位**：多源金融数据平台（采集 → 治理 → 分层 → PIT 特征）＋ 投资者行为审计与建模
- 一句话：**研究对象是「数据」，应用对象才是「投资行为」。**

## 二、为什么要换锚（诊断，全部实测）

旧命题「量化选基 / 温度择时」在本领域**结构上不成立**：

| 结论 | 证据 |
|:---|:---|
| 无执行闭环 | 场外基金**不能程序化下单**；支付宝**没有个人基金 API** |
| alpha 被自己证伪 | 回测：相对沪深300 月度 alpha `p=0.38`、相对中证500 `p=0.56`（[README](../../README.md) 自报）|
| 文献一致 | Carhart(1997) / SPIVA 2025 / Morningstar：主动基金持续性弱、多数跑输 |
| 工程却很好 | 账本复式恒等式 0 不平 · 数据契约 24 项全绿 · `pytest` 835 passed |

⇒ **错的是「命题层」，不是「工程层」。** 所以**不推倒重来，而是切除命题层、把工程层独立成产品。**

**项目唯一被验证的真实价值**（`python src/main.py behavior` 可复现）：追高差 `+2.51pp`、亏损卖出 `22/30`、
持有期中位 15 天、**赎回费漏损 ¥11.18**、同标的择时亏 `7.26pp`。这些**不依赖 alpha、不依赖预测**。

## 四、物理边界：保留 / 归档冻结

**保留并迁移**：上表 L1–L8 各模块（数据层、账本层、PIT 特征、审计三件套、**ML 框架**全是真资产）。

**归档冻结（`git mv` → `legacy/`，不是删除）**：

`sector_analyzer` `sentiment_monitor` `vol_predictor` `vol_model_comparison` `garch_baseline`
`drawdown_warning` `portfolio_simulation` `factor_test` `return_cluster` `shrinkage` `peer_percentile`

**连带同步**（否则工程不自洽）：
- CLI：摘除 `temp/score/sector/sentiment/recommend/strategy/backtest/backtest2/3/4/oos/rebalance`
- Web：摘除 `/api/sectors` `/api/recommend` `/api/quant_models` `/api/rebalance` `/api/sentiment` `/api/funds`(board) `/api/overview`
- 前端：「Research」页与选基/板块组件、6 个 `funds_board_*` 快照变体
- 测试：其对应测试文件移入 `legacy/tests/`

**待定（倾向保留）**：`changepoint`→`audit/`（风格漂移=风险审计）；`multiple_testing`→`ml/`（评估工具）；
`fund_scorer` 的**「低费 + 避坑」排除法**保留为 `features/fund_filter`（费用是预测后续净回报最可靠的单变量之一，[文献] Morningstar）。

## 五、ML 目标重定向（本次核心新增）

- **保留** `recsys_dataset` 的 **PIT 面板构造**（特征只用 ≤t 数据，防泄漏）。
- **换标签**：从「下期收益分位」（预测市场）→「**该笔操作是否亏损 / 是否触发 7 天惩罚费**」（建模行为）。
  - 样本 = 买入批次（实测 **59** 笔）；特征 = 买入时点的市场态（基金前 20 日动量/波动/费率/分位）；标签来自 `holdings`+`transactions`。
  - **小样本要如实声明**；但 **PIT → walk-forward(embargo) → AUC/IC** 的方法论完整，才是答辩得分点。
- 可选补充：对 59 笔做**无监督聚类**（追高型/割肉型行为模式）。
