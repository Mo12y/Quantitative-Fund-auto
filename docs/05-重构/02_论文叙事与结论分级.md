# 02 论文叙事与结论分级（T5.2 产出）

> **用途**：论文/答辩的**叙事骨架 + 结论清单** —— 每条结论都带【陈述分级】与可复现命令/来源。
> **纪律**（执行计划书 §5 + AGENTS 表达纪律）：**不 overclaim**；负结果标"边界"；
> **【文献】≠【实测】**（他人在别的市场上的结论，不得写成本项目实测）。
> 分级定义：【实测】本轮/本项目跑过（附命令或路径）｜【口径】来自项目权威文档（不等于已复现）｜
> 【文献】附可查来源｜【推测】写明依据。
>
> 最后更新：2026-10-16（T0.1/T0.2 数据刷新后，全表数字已按新口径同步）

---

## 一、题目与定位（口径：计划书 §2.1 / §2.2）

- 题目：**《基于多源金融数据的个人基金投资决策支持系统》**。
- 一句话定位：**决策支持，不是决策替代** —— 系统把**度量、对照、证据**递到用户手边；
  用户自己下判断。不选基、不预测收益、不代下单。
- 论文里的落地结构：**行为镜（核心）+ 四个信号（上下文）+ 反事实归因（证据）**。
- ⚠️ **「系统 vs 实例」诚实声明**（必须写进摘要/引言）：当前 **pilot = 1**（作者本人，真实资金），
  "系统"指**分析能力 + 决策支持输出**，**不是**多用户部署的产品。

## 二、正结果主体

### 2.1 行为度量（核心一级交付物）【实测】

**证据**：`docs/00-规范/结论权威口径.md` §六（复现：`python src/main.py behavior`）。

| 可观测量 | 实测值（区间 2026-06-15 ~ 2026-10-15，4.1 个月） |
|:---|:---|
| 追高对照 `chase_spread`（买入前 20 日涨幅中位 − 同基金平常中位） | **+2.58 pp**（正 = 买得比平常更"涨过"） |
| 亏损卖出占比 | **22/30 = 73.3%** |
| 持有期中位 | **15 天**（<7 天惩罚期卖出 2 笔） |
| 卖后 20 日继续上涨（"卖飞"） | 9/24 = 37.5% |

- ⭐ **叙事要点**：行为度量回答「**我自己的操作**值多少」——**不依赖 alpha、不依赖预测**。
  方法上强调两条纪律：① 追高**必须看对照**（差值才说明行为，绝对值会被市场 beta 骗）；
  ② **笔数 ≠ 独立决策数**（30 个批次只落在 10 个卖出日上）。
- ⚠️ **样本充分性声明（必须同页展示）**：区间仅 **4.1 个月** → 系统判定**"不足以判断操作能力"**，
  只给可观测量、不出"我是不是在追高/割肉"的结论。**这不是缺陷，是设计纪律**：
  "数据不足以判断时明说不足以判断"本身就是可写入论文的系统能力。

### 2.2 反事实归因与费率门槛（证据层）【实测】

**证据**：权威口径 §七（复现：`python src/main.py counterfactual` / `sell_rules` / `breakeven`）。

- 核心数字：**实际 XIRR −55.26% vs 完全不动 −61.27% = +601 bp/年**（同期沪深300 −14.84%）
  —— 「操作本身」（几次止损/止盈）相对「完全不动」少亏 601bp/年。
- 卖出规则对比（冻结买入 59 笔）：涨 10% 止盈 −49.34%（本区间最好）/ 跌 5% 止损 −64.67%（最差）。
- 费率门槛：每笔"要涨多少才不亏"；已发生赎回费按档估算 **¥11.18**（其中 <7 天惩罚 2 笔 ¥3.75）。
- ⚠️ 三条读法声明（**必须带**）：只能比 XIRR；标的构成不同 ≠ 纯操作能力；样本极短、不可推广。
- **边界声明（fallback 精神）**：不承诺收益 —— 本节证明的是「当时若完全不动会**多亏** 601bp」，
  **不是**「系统能赚钱」。

### 2.3 风险刻画与"可辩护预测"【实测 + 文献】

**（a）波动率可预测 —— 正**（复现：`python src/analysis/vol_prediction.py` 或
`docs/vol_prediction_report.md` 的生成命令）：
- 四模型同窗口（OOS 2023-01 ~ 2026-08，44 个月、n=8445）：**IC 均值 0.79~0.81**、
  预测分 5 组的组间单调性 **Spearman = 1.0** —— 波动率的可预测性成立。
- 组合层面：vol-targeting **降最大回撤 3.59pp**（17.32% vs 等权 20.91%）—— "预测 → 仓位 → 降回撤"
  链路**有效**。
- ⚠️ **同节如实附的负项（不得省略）**：① vol-targeting 年化 3.07% **低于**等权 6.84%
  （跌后减仓的**踏空成本**）；② **ML 相对简单模型无增量** —— HAR-RV（IC 0.8115）未跑过 EWMA（0.8121）、
  XGBoost（0.8010）未跑过 HAR-RV，"简单模型已接近天花板"。
- ⚠️ 幸存者偏差声明（报告 §十原文要点）。

**（b）回撤预警 —— 弱证据（如实标级）**（复现：`docs/drawdown_warning_report.md` 生成命令）：
- 测试段 RandomForest@8% **AUC 0.7827**、正类召回 70.5%……但 **Bonferroni 校正（×12）后
  p=0.2353 不显著** → 按本项目纪律："**只能当参考，不能当结论**"。

### 2.4 排雷（"可辩护预测"的工程实现）【文献 + 实测】

- **判据与实现**（实测）：同类**夏普分位 ≤ P10（垫底）** 或 **TER 分位 ≥ P90（费率偏高）** →
  触雷；判据数据不可用的持仓进"无法判定"（**不判、不保清白**）—— 复现：`/api/exclusion`
  （`python src/main.py web` 后打开决策台）或 `python scripts/verify_frontend.py` 的七卡断言。
- **文献支撑**（⚠️ **【文献】，不是本项目实测**）：
  - 费率（TER）是预测后续净回报最可靠的单变量之一 —— Morningstar（Kinnel 2016 + 2025 复现）；
    本项目独立核验见 `docs/_archive/参照系接入执行报告.md` §8.5【实测】。
  - 复现研究的一致结论：ML 在基金领域的价值主要在**"稳定地避开差基金"**（bottom decile 年化
    −2%~−3%，显著），而 long-short 超额**几乎全部来自空头腿 —— 散户不可投资**
    （转引自 `docs/_archive/基金推荐系统_ML可行性研究.md` §复现综述）。
- ⚠️ **声明写死**：本项目**没有**做 decile 级显著性检验；排雷是**组内分位判据的工程实现**，
  其可辩护性来自文献 + 制度口径（费率）+ 组内比较方法，**不是**本项目复现的 decile 超额。
  论文里这两者必须分开表述。

### 2.5 数据平台与工程治理（可信度底座）【实测】

- 全市场净值面板 **2,296 万行**（24,155 只有净值）；PIT 特征（扩展窗口分位，只用 ≤ 当日数据）。
- **机制化的诚实**：数据契约 **24 项**只读守卫（含复式记账恒等式、新鲜度覆盖率）；
  `pytest` **544 passed**；前端真机验收 **61 项**全绿；每个"活文档数字"有唯一权威源
  （`docs/00-规范/结论权威口径.md`）且改数字要走引用索引。
- 叙事要点：**"结论能一路指回数据与命令"是这个项目的卖点** —— 例如新鲜度覆盖率
  94.6% 在守卫第 19 条里被机械检验（低于 90% 即红）。

## 三、负结果与边界章节（**不得省略**）

### 3.1 选基 / 收益预测（边界）

- **策略回测**：相对沪深300 月度 alpha p=0.38、相对中证500 p=0.56（**均不显著**）；
  逐年极不稳定（2022、2024 大幅跑输）【实测 · `docs/05-重构/00_重构蓝图.md` 引 README 自查】。
- **滚动样本外验证**（51 个不重叠窗口）：超额中位在 ±0.1pp 内（随机对照修正前 +0.11pp、
  修正后 **−0.09pp**）、逐窗胜率 51.0% —— **看不出优于对照的选基能力**
  【实测 · `docs/_archive/基金推荐系统_ML可行性研究.md` §2.1b】。
- **"主动调仓大幅降回撤"旧结论已撤回**（采样网格错误 + 未计成本造成的假象；修正后
  买入持有 44.5% vs 调仓 43.5%，只差 1pp）。
- **文献一致**：主动基金持续性弱（Carhart 1997；SPIVA/Morningstar）【文献】。
- ⇒ 论文写法：**"选基与收益预测"是边界章节**——负结果**本身**是贡献（严谨证伪 + 换锚依据），
  不是失败；正结果（行为度量/风险刻画）不依赖它。

### 3.2 ML 增量的诚实定位

- 本项目三处 ML 尝试（基金收益排序、波动率、回撤预警）中：**仅回撤预警有校正前的弱信号**，
  波动率与选基均为"简单基线已接近天花板 / 无增量"【实测，见 §2.3、§3.1】。
- ⚠️ **不 overclaim**：不得写"ML 能选基/能预测收益"。

## 五、答辩要点与禁用表述

**预判反问 → 证据化回答**：
- 「你的系统能赚钱吗？」→ 我们证明的不是收益，是**信息差**：同期基准 −14.84% 时，实际操作比
  完全不动**少亏 601bp/年**（§2.2）；且明确声明不承诺收益。
- 「就 1 个人用，算什么系统？」→ 已在摘要声明「系统 vs 实例」（pilot=1）；"系统"=分析能力+输出。
- 「样本才 4.1 个月？」→ 这正是系统的**能力**：样本不足时明确输出"不足以判断"（§2.1），
  而不是硬给结论。
- 「为什么旧命题被砍？」→ 被自己的回测证伪（p=0.38/0.56）；模块归档不删除（`legacy/`）。

**禁用表述（写了就要改）**：
- ❌ "系统能选基 / 预测收益 / 跑赢市场" → ✅ "系统度量行为、刻画风险、给反事实证据"。
- ❌ 把【文献】的 decile 结论写成本项目实测 → ✅ 分开表述（§2.4）。
- ❌ "主动调仓降低了回撤" → ✅ 已撤回的旧结论，修正后仅差 1pp。
- ❌ 用单只基金的数字（如 014143 的 −5.86pp）代表整体 → ✅ 标清单只与样本量。
