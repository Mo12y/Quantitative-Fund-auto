1. **申万分类回溯偏差**: 申万一级行业在2021年10月由28个修订为31个，akshare提供的新版指数在2021年前的数据为回溯拼接（用新分类倒推历史成分），并非当时真实可投资的指数，存在前视偏差风险。本测试采用方案A（全区间统一使用回溯数据）。

3. **交易成本假设**: 单边0.5%，模拟场外C类份额或ETF联接的实际成本。
4. **幸存者偏差**: 使用当前存续行业指数，未考虑已撤销行业。
5. **样本长度**: 141个月。若结论为不显著，需注意样本量不足导致检验功效低，不代表因子一定无效。
6. **基准类型判定**: 按 `index_code` 白名单显式判定（`total_return` / `price_only` / `unknown`），判不出来就报 unknown —— 旧版用 `("H00300" in head) or ("close" in head.lower())`，CSV 表头永远是 `date,close`，所以恒为 True，等于无条件宣称用了全收益指数。

## 十、系统转型建议

基于天花板测试结论，建议将系统定位从**追求alpha**转向**资产配置+定投纪律+风控**。具体如下：

### 可保留的模块

- **市场温度计**: 保留风控价值。温度虽不能创造alpha，但对控制仓位、降回撤有效。
- **持仓跟踪**: 继续保留，作为用户账户管理基础。
- **定投管理**: 保留，定投纪律本身是长期收益的重要来源。
- **回测引擎**: 保留严谨的防未来函数框架，可用于验证资产配置策略。

### 应简化或移除的模块

- **复杂的6因子基金评分**: 简化为风格+费率+规模的基础筛选，不做alpha排序。
- **行业轮动相关**: 移除 `sector_analyzer` 的择时推荐功能，仅保留行业温度展示。
- **自适应选基实验**: 已证伪，移除。

### 应优先加强的模块

- **用户画像与风险分层**: 根据用户风险承受能力给出股债配置中枢。
- **再平衡提醒**: 基于目标仓位的偏离度触发再平衡（如偏离>5%提醒）。
- **资产配置策略库**: 提供恒定混合、生命周期、风险平价等配置方案的回测对比。
- **定投+估值增强**: 温度计低时多投、高时少投的估值定投增强（已验证有效降回撤）。
