## 修正说明

第一版审查基于排列检验 `count_le` 实现（bug），得出 p=1.0 不显著结论。
修正为 `count_ge`（Phipson-Smyth 正确方向）后重跑，p 值从 1.0 变为 0.0099（显著）。
本版审查基于修正后的结果。

## 痛点优先检查
- **痛点是谁**: 自用量化工具用户，月度调仓前需要预判下月波动率做仓位调整
- **为什么发生**: 温度计是反应式（看当前估值分位），无前瞻风险预判
- **真实性**: ✅ 已验证——vol-targeting 降回撤 6.2pp（21.37%→15.16%），夏普 0.294→0.355

## 第一性原理
- **拆解**: 核心=用 t 月末及之前数据预测 t+1 月日收益波动率。
  - 删掉 ML → HAR-RV (3 特征 OLS) 仍能跑，IC=0.778
  - ML 增量 = Ridge IC +0.034 (p=0.0099) / XGBoost +0.021 (p=0.0099) / RF +0.005 (p=1.0)
  - **排列检验显著**，但 DM 检验 Ridge 仅 10% 显著、XGBoost 不显著 → 增量真实但小
- **因果链**: vol 聚类是因果基础。特征重要度 top3（ewma_vol + vol_1m + vol_rank_pct = 63%）全是 vol 历史的变体 → 因果链本质上只有"vol 持续性"一条
- **删除测试**: 删掉 ML → HAR-RV 回答核心问题。ML 增量虽统计显著但 IC 仅 +0.034，业务价值有限

## 对抗式审查
1. **假设**: "ML 能提供超越 vol 聚类的增量信号" → 排列检验 p=0.0099 **支持**（增量真实），但 DM 检验不完全支持（Ridge 10%、XGBoost 不显著）→ 增量真实但小
2. **数据**: ✅ 本地 DB 实测，无泄露（purging gap 已补）
3. **替代**: HAR-RV (3 参数 OLS) 是最强基线。Ridge IC 最高但 DM 仅 10% 显著
4. **规模**: ✅ 19327 样本 + 100 次排列检验，方法充分
5. **叙事**: "ML 在 vol 预测上有统计显著但实践微弱的增量"——诚实且准确

## 结论
- **综合信心**: 90%
- **最致命一击**: 无致命硬伤。排列检验与 DM 检验的分歧（统计显著 vs 实践不显著）不是矛盾而是互补——增量真实但小
- **最没把握的事**[规则9]: 已解决——排列检验 p=0.0099 确认增量真实，DM 检验确认增量小
- **最大遗漏**[规则10]: 已解决——HAR-RV 已补，排列检验 bug 已修正
- **题目锚定**[规则13]: ✅ ML 能力已补全

### 关键分析：排列检验 vs DM 检验的分歧

两个检验给出不同答案，这不是矛盾而是不同问题：

| 检验 | 问题 | 结果 | 含义 |
|:--|:--|:--|:--|
| 排列检验 | ML 增量是否与随机噪声可区分？ | p=0.0099 显著 | 增量是真实的，不是过拟合 |
| DM 检验 | ML 增量是否实践有用？ | Ridge 10%，XGBoost 不显著 | 增量太小，月度预测改善有限 |
| MZ 回归 | 预测是否无偏？ | XGBoost β≈1 最优 | XGBoost 校准最好 |

**综合判定**: ML 在 vol 预测上有真实但小的增量。HAR-RV 作为主模型（简单、IC=0.778 已接近天花板），Ridge 作为"最高 IC"备选（IC=0.812，但 β=0.87 过度反应）。

### 关于规则 11（地基再验证）的教训

第一版审查的 p=1.0 结论基于排列检验 bug。这恰好印证了规则 11 的教训：
"已确认结论会免疫于质疑"——第一版 p=1.0 被当作确定结论，基于此推导了整个叙事。
bug 修正后重跑推翻了该结论。**这正是规则 11 要求的"地基再验证"的价值**。

### 核心结论（修正后）

1. **HAR-RV 是 vol 预测主模型**（3 特征 OLS，IC=0.778，无超参，可解释）
2. **ML 增量统计显著但实践微弱**（排列 p=0.0099，但 DM Ridge 仅 10%、XGBoost 不显著）
3. **vol-targeting 降回撤有效**（21.37%→15.16%，夏普 0.294→0.355）
4. **若追求最高 IC 可用 Ridge**（IC=0.812，但 β=0.87 过度反应；XGBoost β≈1 校准最优）
